# Fiches DSCG

Outil pour créer, ranger et exporter ses fiches de révision du DSCG : schémas, tableaux, synthèses, encadrés et formules, sur une ou plusieurs pages A4.

Tout tient dans `index.html`. Les fiches sont enregistrées dans le navigateur de l'appareil utilisé : pense à télécharger régulièrement une sauvegarde (Accueil → Personnaliser → Télécharger une sauvegarde).
